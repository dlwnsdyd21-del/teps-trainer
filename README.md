# 🎯 TEPS 트레이너

목표 텝스 점수에 맞는 레벨(하/중/상)로 **단어 암기 · 예문 해석 · 문제 풀기**를 훈련하는 웹 앱입니다.
설치나 서버 없이 브라우저만 있으면 동작합니다.

## 실행 방법

- 가장 간단한 방법: `index.html`을 더블클릭해서 브라우저로 엽니다.
- 로컬 서버로 열고 싶다면 (선택):

```bash
python -m http.server 8734
```

후 브라우저에서 `http://localhost:8734` 접속.

## 레벨 구성 (뉴텝스 600점 만점 기준)

| 레벨 | 목표 점수 | 등급 | 의미 |
|------|-----------|------|------|
| 하 · 기초 | 327점+ | 2급 | 인증서 발급 기준, 서울대 이공계 대학원 등 최소 요건 |
| 중 · 중급 | 387점+ | 2+급 | 공무원·국가자격시험 기준(340점)을 여유 있게 상회 |
| 상 · 고급 | 453점+ | 1급 | 상위권 대학원·전문직 수준 |

공식 등급표: 1+급 526~600 / 1급 453~525 / 2+급 387~452 / 2급 327~386 / 3+급 268~326 / 3급 212~267
(출처: [TEPS 공식 사이트 — 채점방식 및 등급체계](https://m.teps.or.kr/info/Teps3))

## 학습 모드

- **단어 암기** — 레벨별 80단어. 카드를 뒤집어 뜻·예문 확인, "알아요/몰라요"로 분류. 모르는 단어는 세션 뒤에 다시 등장. 뜻 맞히기 4지선다 퀴즈 포함. 🔊 버튼으로 발음 듣기(TTS).
- **예문 해석** — 레벨별 40문장. 영어 문장을 먼저 해석해 보고 "해석 보기"로 정답 확인. 해석 포인트(구문/문법)와 핵심 어휘 제공. O/X 자가 채점으로 "다시 볼 문장"만 골라 복습 가능.
- **문제 풀기** — 레벨별 30문제(어휘 10 / 문법 10 / 독해 10), 뉴텝스 실전 유형. 10문제 랜덤 세트로 풀고 즉시 채점 + 한국어 해설. 틀린 문제는 **오답노트**에 자동 저장.

학습 기록(암기한 단어, 해석 완료 문장, 정답률, 오답노트)은 브라우저 `localStorage`에 저장되어 껐다 켜도 유지됩니다.

## 폴더 구조

```
TEPS APP/
├── index.html        # 진입점
├── css/style.css     # 스타일
├── js/app.js         # 앱 로직 (화면 전환, 학습 기록, 채점)
└── data/
    ├── low.js        # 하 레벨 콘텐츠 (단어/예문/문제)
    ├── mid.js        # 중 레벨 콘텐츠
    └── high.js       # 상 레벨 콘텐츠
```

콘텐츠를 추가하고 싶으면 `data/*.js`의 배열에 같은 형식으로 항목을 추가하면 됩니다.
